# Buthaina Osama Portfolio

## How to run in VS Code

1. Open this folder in VS Code.
2. Put your real profile photo in `images/profile.jpg`.
3. Put your About photo in `images/about.jpg`.
4. Replace the six project images:
   - images/project1.jpg
   - images/project2.jpg
   - images/project3.jpg
   - images/project4.jpg
   - images/project5.jpg
   - images/project6.jpg
5. Put the real inDrive video at:
   `videos/indrive.mp4`
6. Put your CV PDF at:
   `CV/Buthaina-CV.pdf`
7. Open `index.html` in a browser.

For the easiest development workflow, install the VS Code extension "Live Server",
then right-click `index.html` and choose "Open with Live Server".

## Important
The project uses only:
- HTML
- CSS
- Vanilla JavaScript

No React, Bootstrap, Tailwind, or other frameworks are required.
